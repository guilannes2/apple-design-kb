## Síntese visual da página search-fields
- Grande parte das ilustrações usa mockups de tela real (barra de status "9:41", teclado do sistema) para mostrar o campo de busca em contexto, sempre com o texto de exemplo "Design" preenchido e uma lista de sugestões ou tokens logo abaixo, mudando apenas a plataforma (iPhone, iPad, Mac, tvOS).
- Diagramas com chamadas (setas e rótulos de texto apontando para partes da tela, como em img 0984) são usados quando é preciso nomear componentes específicos da interface (barra de escopo, tokens), diferente das ilustrações mais simples e genéricas de barra de abas (imgs 0985, 0986, 0992) que comparam duas variações lado a lado.
- Comparações de variação de layout (aba de busca dentro do grupo vs. separada; busca na barra inferior vs. superior) são sempre mostradas como pares de imagens quase idênticas, mudando só a posição de um elemento, sem uso de selos de certo/errado nesta página.
- A medida do campo de busca (img 0983) é o único caso desta página com anotação de dimensão (setas de largura e altura), reforçando que a estilizada imagem de abertura funciona como referência de proporção do componente, não como mockup de app real.
