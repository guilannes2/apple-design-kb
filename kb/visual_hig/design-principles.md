## Síntese visual da página design-principles
- As oito imagens do lote formam um sistema de ícones absolutamente consistente: mesmo estilo de traço grosso arredondado ou preenchimento sólido, mesmo gradiente verde (claro para escuro/teal), mesmo tamanho relativo e posicionamento centralizado à esquerda do quadro, mesma ausência de texto ou legenda, reforçando que cada princípio de design é representado por um pictograma único e memorável, não por fotografia ou composição de interface.
- A escolha de símbolo para cada princípio é literal/metafórica direta: alvo para "Design principles" (foco geral), figura humana de braços abertos para "Purpose" (a pessoa no centro da intenção), duas figuras de mãos dadas para "Agency" (relação de confiança e ação conjunta), casa para "Responsibility" (segurança, lar), setas cruzadas para "Familiarity" (orientação, movimento conhecido), tesoura para "Flexibility" (corte, adaptação), compasso para "Simplicity" (precisão, desenho técnico enxuto) e coração para "Craft" (cuidado, dedicação).
- Todas as folhas desta página trazem só a versão clara, sem nenhuma versão escura no lote, e a descrição oficial de cada ícone bate integralmente com o que a imagem mostra, sem divergências identificadas.
