## Síntese visual da página token-fields
- A imagem de abertura de seção (img 1160) usa a mesma linguagem de gradiente laranja/vermelho das outras páginas, mas aqui o conceito ilustrado é a coexistência de um token (pílula com ícone) e texto solto no mesmo campo, diferente de text-fields e text-views que mostram só texto puro.
