## Síntese visual da página app-clips
- Toda a família de ilustrações mantém o mesmo vocabulário de "selo circular de veredito" (X cinza para inválido, check verde para correto) reaproveitado em várias páginas das HIG, aqui usado para julgar variações do App Clip Code (img 0063, img 0065).
- Regras numéricas duras (ângulo de 60° para superfície cilíndrica, diâmetro mínimo de 3/4", espaço livre "x" uniforme) são sempre mostradas como diagrama técnico com cotas e linhas de medida, nunca só descritas em texto (img 0061, img 0067, img 0068, img 0070).
- Erros de customização (proporção, gradiente, sombra) são sempre demonstrados um por vez, isolando exatamente a variável errada mantendo o resto do desenho idêntico ao código correto (img 0073, img 0074, img 0075).
- A jornada de uso é sempre contada em dois planos simultâneos, cenário físico ilustrado (mesa, totem, pessoas) e tela do iPhone em destaque circular, ligados por uma linha ou círculo azul de foco (img 0060, img 0071).
- O cartão de App Clip (App Clip card) segue um layout fixo reaproveitado com dados diferentes: imagem de fundo, título, descrição curta, botão de verbo variável, selo de atribuição "Powered by" (img 0054, img 0056).
- A anatomia do próprio código (ícone central, anéis tracejados, logotipo) e a anatomia de cor (fundo, gerada, primeiro plano) são ensinadas com o mesmo recurso gráfico de linhas de chamada horizontais apontando para cada parte (img 0059, img 0076).
