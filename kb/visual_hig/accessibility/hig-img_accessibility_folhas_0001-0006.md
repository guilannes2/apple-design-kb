## Síntese visual da página accessibility
- Cada subtema da acessibilidade (Vision, Hearing, Mobility, Speech, Cognitive) recebe a mesma faixa horizontal amarela arredondada com exatamente cinco pictogramas em marrom, sempre igualmente espaçados: é um padrão de módulo reutilizável de "resumo de tema" que se repete com ícones trocados (img 0001, 0012, 0014, 0019, 0020).
- Comparações de certo/errado usam sempre o mesmo par de símbolos: círculo verde com check versus círculo vermelho com X ou octógono, colocados lado a lado sem rótulo de texto (img 0005/0007, img 0010/0011).
- Contraste de cor é mostrado com um cartão dividido ao meio, metade clara rotulada "Light" e metade escura rotulada "Dark", com a mesma forma colorida sobreposta às duas metades para comparar como a cor se comporta nos dois modos (img 0008, 0009).
- Espaçamento entre controles é ilustrado com contornos vermelhos tracejados desenhados sobre a área de toque real dos botões, deixando visível quando essas áreas se tocam (img 0016), contra a mesma composição sem os contornos quando o espaçamento é suficiente (img 0015).
- Fluxos de interface (edição de lista, Assistive Access) são mostrados como sequência de dois estados quase idênticos com uma diferença pontual: um botão revelado por swipe cobrindo texto (img 0017 para 0018), ou uma tela com menos opções após avançar no fluxo (img 0021 para 0022).
- Peso e tamanho de fonte são comparados usando a mesma palavra "Hello" dentro do mesmo tipo de cartão cinza, variando só peso e tamanho entre as duas imagens (img 0002, 0003).
- Em visionOS, o recurso de zoom é mostrado com uma lente circular sobreposta a uma cena 3D real, ampliando apenas a região sob ela, diferente das ilustrações planas do restante da página (img 0023).
