- A HIG usa uma notação gráfica única e consistente para representar haptics sem som: barras verticais rosa grossas para pulsos discretos, um leque triangular de linhas azuis/rosa para vibração contínua que decai, e uma linha pontilhada fina para a cauda quase inaudível; um marcador branco de tempo percorre cada desenho e volta ao início quando o clipe se repete (folha 026, todos os quadros; folha 032, folha 034).
- A quantidade e o tamanho dos pulsos iniciais isolados é o principal código visual que diferencia cada haptic entre si: dois pulsos para Notification/Up/Down (folhas 026, 027, 028), três pulsos para Success (folha 029), um pulso só para Start (folha 032), e duas cópias inteiras do mesmo pulso simples lado a lado para Stop (folha 033).
- Falha e Retry usam uma construção gráfica totalmente diferente das demais: um bloco retangular sólido preenchido com textura densa e irregular, em vez de pulsos separados seguidos de leque (folhas 030 e 031); nas capturas vistas, Failure e Retry aparecem com a mesma forma, sem diferença visual perceptível entre os dois.
- O haptic Click (folha 034) é o único com amplitude visivelmente menor e sem leque de decaimento grande, reforçando visualmente a ideia de um toque muito breve e sutil, distinto de todos os outros haptics do conjunto.
