- Controles de propriedade contínua com preview ao vivo: sliders (Blur, Translucency), um controle bidimensional de arrastar para Refraction (folha 0005) e um controle de arrastar 2D específico para Specular/composição, todos mudando a imagem do ícone no canvas em tempo real a cada ajuste, quadro a quadro. A fala menciona os efeitos (refração, blur) em termos de sensação ("frosted glass", "sunflower"), mas as imagens mostram os valores numéricos exatos que acompanham cada ajuste.
- Menus suspensos como lista vertical com marca de seleção: tanto o campo Fill (folha 0003: Automatic/Solid/Gradient/System Light/System Dark) quanto o campo Blend Mode (folha 0021: Normal/Darken/Multiply/Plus Darker/Lighten/Screen/Plus Lighter/Overlay/Soft Light/Hard Light) usam o mesmo padrão de menu: lista vertical, item ativo com check, item sob o cursor destacado em azul.
